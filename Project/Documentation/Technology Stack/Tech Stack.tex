	\section*{Technology Stack}
	Our project's technology stack is a specific selection of tools and frameworks, chosen for scalability and synergy for a web application. We have designed an architecture that is multi-tiered designed to ensure great performance, security, and maintainability.
	
	\section*{Frontend}
	On the client-side interface we will be implementing our build using HTML, CSS, and JavaScript. We are using the Bootstrap framework for a responsive design that maintains a consistent user experience across devices and screen sizes. Utilizing this framework will give us enhanced accessibility with its built-in components and grid system. 
	
	\section*{Backend}
	Server side logic will be implemented using PHP and JAVA. PHP will handle the core logic and server-side scripting, along with data processing. Java will be utilized for the more complex, object-oriented tasks for performance that will be exceptional for integrating external APIs. We will also be using SQL for our database interactions.
	
	\section*{Database}
	The database layer will be powered by MariaDB. MariaDB's high performance, reliability, and feature set will be critical in handling advanced indexing and query optimization. It will serve as our central repository for all of the application data, such as user profiles, user personal data and other persitant data.  
	
	\section*{Version Control and Collaboration}
	Git will serve as our primary version control system, with GitHub providing the centralized repository and collaborative platform. This allows for distributed development, enabling each team member to work on separate features in isolated branches before merging them. We will implement a feature-branch workflow with pull requests for code reviews to ensure code quality and prevent integration issues.
	
	\section*{Communication}
	Discord will be our primary communication hub. Its features, including dedicated channels for different topics (e.g., bug reports, feature discussions, and general announcements) and voice chat capabilities, facilitate real-time communication and team cohesion. This ensures that all team members remain synchronized and can quickly resolve issues as they arise.
