UserDAO Class Documentation

This class provides methods to interact with the user table in a database. It allows creating, retrieving, updating, and authenticating users.

addUser(string $username, string $password, string $email, int $roleID): void

Inserts a new user record into the database with a hashed password.

  • $username — User’s username.
  • $password — Plain text password, hashed before insertion.
  • $email — User’s email address.
  • $roleID — Numeric role identifier.
Example Usage 

$dao = new UserDAO();

$dao->addUser(
    "jdoe",
    "securePass123",
    "jdoe@example.com",
    2
);

getUserByID(int $userID): User|null

Retrieves a user by their unique ID. Returns a User object or null if not found.

  • $userID — User’s numeric identifier.
Example Usage 

$dao = new UserDAO();

$user = $dao->getUserByID(5);

if ($user) {
    echo $user->getUsername();
}

getUserByName(string $username): User|null

Retrieves a user by their username. Returns a User object or null if not found.

  • $username — Username to search for.
Example Usage 

$dao = new UserDAO();

$user = $dao->getUserByName("jdoe");

if ($user) {
    echo $user->getEmail();
}

updateUser(User $user): void

Updates an existing user record. If the password is new and unhashed, it will be rehashed automatically.

  • $user — A User object with updated data.
Example Usage 

$dao = new UserDAO();

$user = $dao->getUserByID(5);

$user->setEmail("newmail@example.com");
$user->setPassword("newPass123");

$dao->updateUser($user);

authenticate(string $email, string $passwd): User|null

Authenticates a user by verifying the provided email and password. Returns the User object if credentials are valid, or null otherwise.

  • $email — User’s email address.
  • $passwd — User’s plain text password.
Example Usage 

$dao = new UserDAO();

$user = $dao->authenticate(
    "jdoe@example.com",
    "securePass123"
);

if ($user) {
    echo "Login successful: " . $user->getUsername();
} else {
    echo "Invalid credentials.";
}

PostDAO Class Documentation

This class provides data access operations for the post table, including creating, retrieving, and deleting posts.

addPost(int $userID, int $threadID, string $contents, string $caption, string $visibility): void

Inserts a new post record into the database.

  • $userID — ID of the user creating the post.
  • $threadID — ID of the thread the post belongs to.
  • $contents — Main content of the post.
  • $caption — Caption or title for the post.
  • $visibility — Visibility setting (e.g., public, private).
Example Usage 

$dao = new PostDAO();

$dao->addPost(
    3,                 // userID
    7,                 // threadID
    "This is my post content.",
    "My first post",
    "public"
);

getAllPosts(): array

Retrieves all non-deleted posts from the database, ordered by creation date (newest first).

Returns an array of Post objects.

Example Usage 

$dao = new PostDAO();

$posts = $dao->getAllPosts();

foreach ($posts as $post) {
    echo $post->getCaption() . " - " . $post->getContents();
}

getPostsByUser(int $userId): array

Retrieves all non-deleted posts created by a specific user, ordered by creation date (newest first).

  • $userId — ID of the user whose posts are being fetched.

Returns an array of Post objects.

Example Usage 

$dao = new PostDAO();

$userPosts = $dao->getPostsByUser(3);

foreach ($userPosts as $post) {
    echo $post->getCaption();
}

deletePost(int $postID): void

Marks a post as deleted by setting its is_deleted field to TRUE.

  • $postID — ID of the post to delete.
Example Usage 

$dao = new PostDAO();

$dao->deletePost(15);

CommentDAO Class Documentation

This class provides data access operations for the comment table, including adding, retrieving, and deleting comments.

addComment(int $userID = -1, int $postID = -1, string $contents = ''): void

Inserts a new comment into the database for a specific post and user.

  • $userID — ID of the user posting the comment (default: -1).
  • $postID — ID of the post being commented on (default: -1).
  • $contents — Text content of the comment.
Example Usage 

$dao = new CommentDAO();

$dao->addComment(
    4,                     // userID
    12,                    // postID
    "This is an insightful post!"
);
